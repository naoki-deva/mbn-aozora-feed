# クライアントの設計

## 接続と状態

`src/lib/session.ts` がゲストの公開AppViewと、アプリパスワードで認証したPDSのAgentを管理します。SDKがセッションを更新し、PDSの移動先も解決します。HTTPSのカスタムPDSを指定できます。通常のAPI呼び出しは30秒でタイムアウトし、読み取りのみ一度再試行します。書き込みは自動再試行しません。

セッション更新時には保存先を維持します。アカウントの切り替え・ログアウトでは実行中の読み取りをキャンセルし、Queryキャッシュを消去します。古いAgentのセッション保存コールバックを停止し、終了したセッションが保存し直されるのを防ぎます。キャッシュキーにもアカウントDIDを含めます。

`src/lib/preferences.ts` がアカウント別の端末設定を検証・保存します。ゲストの選択は初回ログイン時にだけ引き継ぎます。フィードがゼロでも有効な状態です。起動時は指定されたホームフィードを優先し、普段のタブ切り替えは現在の選択だけを変えます。

## フィードを勝手に選ばない

SDKの `Agent.getPreferences()` は、v2のフィード設定が存在しない場合に「フォロー中」を追加してサーバーへ保存するマイグレーションを含みます。ここでは `src/lib/remote-preferences.ts` が `app.bsky.actor.getPreferences` を直接呼び、既存設定を読み取るだけにしています。古いフィード設定を読む場合も、新しいフィードの挿入やサーバーへの保存をしません。

サーバーの固定フィードを更新するのは、利用者が「保存する」を選んだ場合のみです。端末の並べ替えや削除は自動同期しません。保存時は他クライアントの未固定フィードを維持します。読み込みは今のホームへ選択済みフィードを追加し、既存の順番を維持します。

## 投稿とメディア

`src/lib/api.ts` が公式RichTextを使い、UTF-8のバイト位置に対応したファセットを生成します。300文字制限はUnicodeの書記素で判定します。返信は親から会話のルートを引き継ぎます。

投稿・threadgate・postgateは同じTIDを使って `com.atproto.repo.applyWrites` で一括保存します。投稿だけ成功して返信制限が付かない状態を避けます。既存の制限の変更も一括保存し、レコードCID・コミットCIDを確認します。返信の非表示や引用の解除は既存ルールを維持し、`swapRecord` で別クライアントの更新との競合を検出します。

画像はJPEG・PNG・WebP、1枚1MB以下、4枚までです。自動圧縮やEXIFの除去はまだありません。動画は100MB以下のMP4を選択し、公式動画サービス用のサービス認証を取得してアップロード・処理状況を監視します。実際のアカウントの容量・動画時間などの制限はサービス側が決定します。メール確認などが必要な場合はAPIエラーを表示します。処理は最大10分でタイムアウトします。

HLS.jsは動画を表示する時だけ読み込み、ネイティブHLSに対応するブラウザでは標準プレイヤーを利用します。自動再生はしません。メディア処理完了後の投稿が失敗した場合、アップロード済みBlobの参照は投稿に保存されません。

## モデレーション

ログインを表示状態へ反映する前に、アカウントのラベル・ミュート設定を読み、Agentのラベラーヘッダーを設定します。`moderatePost`・`moderateProfile`・`moderateNotification`・`moderateFeedGenerator`・`moderateUserList` で公式SDKの判定を使います。カスタムラベル定義が読み込まれるまでは投稿を表示しません。

引用は引用元の作者・レコード・ラベルを独立して判定します。ブロック、削除、引用解除を区別します。`noOverride` のメディアは「表示する」ボタンを出しません。ゲストによるセンシティブな画像の解除をブラウザテストで検証します。

未知のレコードは本文として無理に描画せず、公式Lexiconの検証で既知の投稿を判定します。Reactでテキストを描画し、HTMLを挿入しません。外部リンク・画像・動画はHTTP/HTTPSのURLに限定します。

## ホスティング

`dist/` は静的配信できます。SPAのURLは `index.html` へフォールバックさせてください。HTTPSはログイン情報・クリップボード・動画等に必要です。APIキーやAPIプロキシサーバーは不要です。CORSは接続先PDSの設定に従います。

本番のヘッダー例（利用するカスタムPDS・メディアの接続先に合わせて調整してください）:

```text
Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; connect-src 'self' https:; img-src 'self' https: data: blob:; media-src 'self' https: blob:; worker-src 'self' blob:; font-src 'self'; base-uri 'none'; frame-ancestors 'none'
Referrer-Policy: no-referrer
X-Content-Type-Options: nosniff
Permissions-Policy: camera=(), microphone=(), geolocation=()
```

認証トークンはブラウザのストレージに保存されるため、同じオリジンに信頼できないスクリプトを追加しないでください。このアプリは解析ツール・広告SDK・外部フォントを読み込みません。HLSを含むSDKのチャンクは大きく、低速回線の起動速度の改善は残課題です。
