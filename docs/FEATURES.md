# 機能の対応範囲

このリポジトリはREADMEだけの状態から、BlueskyのWebクライアントを新規実装したものです。「Blueskyの全機能」を完全に実装・検証し終えたというリリースではありません。以下に今回の実装、公式アプリへ委ねた操作、今後の実装を明示します。

## 今回実装した機能

| 分野               | 対応内容                                                                                                                        | 検証                                                                             |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| フィードの自由選択 | 初回に固定フィードなし、ホーム追加・全削除・並べ替え・起動時選択、フィード検索、AT URI入力、リストフィード                      | ユニット + PC/モバイルE2E、公開APIの取得スモーク                                 |
| 設定の同期         | 自分で実行するBluesky設定の読込・固定フィード保存、端末設定のJSON入出力                                                         | 読み取り時に書き込みをしないユニットテスト                                       |
| 認証               | アプリパスワード、カスタムPDS、トークン更新、端末保存の選択、複数アカウント、ログアウト                                         | セッション保存ユニット + 模擬ログインE2E                                         |
| 投稿               | テキスト、返信・引用、ファセット、言語、自己ラベル、画像4枚とALT、MP4、リンクカード                                             | 投稿制限・ルート継承・一括保存ユニット + 模擬投稿E2E                             |

実アカウントの資格情報を持っていないため、テストで実際の投稿・フォロー・DM・モデレーション設定変更は行っていません。公開フィード一覧のAPIへの実通信は確認しています。模擬APIのテスト成功は、認証済みサーバーとの全操作の実通信成功を意味しません。

## 公式Blueskyへ案内する操作

- アカウント新規作成、アプリパスワードの発行・取消、メール確認・変更、パスワードの変更・回復。
- アカウントの停止・削除、PDS移行、リポジトリのエクスポート、年齢確認・個人情報の管理。
- カスタムドメインのDNS/HTTPS設定手順（ハンドル変更自体はクライアントから実行できます）。

設定画面のリンクから公式アプリへ移動できます。これらを当クライアント内の機能として実装済みとは数えません。

## 未実装・今後の対応

1. OAuth認証。公開オリジン・クライアントメタデータ・リダイレクトURIを確定して追加する必要があります。現状はアプリパスワード認証です。
2. OS・ブラウザへのプッシュ通知、通知用Service Worker、PWAのインストール・オフライン閲覧。現状はアプリ内の通知とポーリングです。
3. iOS/Android/デスクトップのネイティブアプリ配布。
4. 公式のGIF検索、動画字幕の作成・アップロード、画像の自動圧縮・EXIF除去、複数投稿の連続作成と下書きの永続保存。
5. グループの参加リンク・招待リンク、参加申請の管理、グループのロック・管理者権限、DMでの返信引用・投稿共有の作成。
6. スターターパックの編集・一括フォロー・QR共有、リストやスターターパックからの退出・参照リストのオプトアウト。
7. 複数の返信許可ルール・ユーザーリストを組み合わせる編集UI。既存のカスタムルールは、投稿後の設定変更画面で維持できます。
8. フィードの作成・アルゴリズムのホスティング、ラベラーサービスの運営、公式の興味登録・トレンド・ライブイベント・外部連携の全設定。
9. 全文多言語UI、自動翻訳、通知種類の完全網羅、既読位置・スクロール位置の復元。
10. セッションのタブ間同期、設定同期の同時編集時の競合表示、低速回線の起動速度、広範な本番・アクセシビリティ検証。

## 実アカウントでの受け入れ検証

専用のテストアカウント2つとテスト用PDSを使い、以下を確認してください。

- ログイン・期限切れ・トークン更新・カスタムPDS・アカウント切替・ログアウト。古いアカウントのデータが表示されないこと。
- フィードの読込・保存で、他クライアントの未固定フィードや無関係な設定が維持されること。
- 日本語/絵文字/メンション/リンク/タグ、画像とALT、動画のアップロード・制限・処理失敗、引用と返信のルート。
- フォロー、いいね、リポスト、ブックマーク、プロフィール編集、投稿削除・固定。
- 返信制限・引用制限の投稿時/投稿後の動作、別クライアントとの競合、返信の非表示と引用解除。
- 通知の既読・通知設定、DMの権限不足・リクエスト・送受信・リアクション・報告・退出、グループの制限。
- リストとメンバー、モデレーションリスト、スターターパックの作成と削除。
- 期限付きミュート語、ブロック、カスタムラベラー、成人向けコンテンツ、引用・プロフィール・通知からの表示漏れ。
