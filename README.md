# あおぞら / Aozora

**自分の空を、自分で選ぶ。** フィードの自由選択を中心にした、PC・スマートフォン対応の非公式Bluesky Webクライアントです。フィードジェネレーターのサーバーではなく、Blueskyの公開API・PDS・チャットAPIを利用するクライアントアプリとして実装しています。

初回のホームは白紙です。興味のあるフィードを選び、順番と起動時に表示するフィードを指定できます。「フォロー中」も自分で選ぶ項目のひとつです。

## 起動する

Node.js **22.12以降**（CIは24）、npmが必要です。

```sh
npm ci
npm run dev
```

`http://localhost:5173` を開きます。APIキーや独自バックエンドは不要です。閲覧はログインなしで利用できます。

```sh
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run preview
```

ビルド成果物は `dist/` に出力されます。本番環境ではHTTPSで配信し、`/profile/...` や `/post/...` などの直接アクセスを `index.html` へフォールバックさせてください。

## 使える機能

- フィードの初回自由選択、検索・追加・削除・並べ替え・起動時の選択、リストフィード、Blueskyとの明示的な読み込み・保存。
- アプリパスワードでのログイン、カスタムPDS、セッション更新、保存済みアカウントの切り替え。
- 投稿・返信・引用、メンション・リンク・ハッシュタグ、画像4枚と代替テキスト、MP4動画、リンクカード、投稿言語、コンテンツの自己ラベル。
- いいね・リポスト・ブックマーク、削除・プロフィールへの固定、返信できる人と引用の許可設定。投稿後の変更、返信の非表示、引用との接続解除。
- スレッド・返信の並び替え、いいね・リポストした人・引用投稿の一覧、投稿・ユーザー・フィードの検索と投稿の絞り込み。
- プロフィール、フォロー・フォロワー、プロフィール・画像編集、個別ユーザーの投稿通知。
- 通知と未読数、既読操作、通知の種類・対象の設定。
- DMの会話一覧・送受信・承認・ミュート・退出・削除・リアクション・報告。グループの作成・閲覧・名前変更・メンバーの追加と削除。
- ユーザーリストの作成・編集・削除・メンバー管理、モデレーションリストのミュート・ブロック、スターターパックの閲覧・作成・削除。
- ミュート・ブロック・報告、ミュートワードの期限・対象設定、ラベラーの購読・ラベル設定、非表示投稿の復元。
- ライト・ダーク・端末設定に合わせたテーマ、コンパクト表示、数字の非表示、返信・リポスト・引用・メディアの表示フィルター、設定ファイルの書き出し・読み込み。

**公式アプリの全機能との完全な同等性は、現時点では達成していません。** OAuth、端末プッシュ通知、公式のGIF検索、アカウント新規登録・メール・パスワード・移行管理、一部の高度なグループ操作などの対応状況は [機能対応表](docs/FEATURES.md) を参照してください。機能の実装と、実アカウントでの受け入れ検証も区別しています。

## ログインについて

Blueskyの [設定 → アプリパスワード](https://bsky.app/settings/app-passwords) で発行したパスワードを使ってください。DMを使う場合は、メッセージへのアクセスを許可して発行する必要があります。

アプリパスワード自体は保存しません。セッションのアクセストークン・更新トークンは通常 `sessionStorage` に保存します。「この端末でログインを保持」を選んだ場合のみ `localStorage` に保存します。ログアウトで現在のアカウントの保存済みセッションを削除します。共有端末ではログインの保持をオフにしてください。

フィード・表示設定はゲストとアカウントごとに保存します。初めてログインした際は、ゲストとして自分で選んだフィードを引き継ぎます。設定ファイルの書き出しにセッション情報は含みません。

## 設計と検証

React + TypeScript + Vite、公式 `@atproto/api` SDK、TanStack Query、React Router、HLS.jsを使用します。

- [設計・データの扱い](docs/ARCHITECTURE.md)
- [機能対応・残課題・受け入れ検証](docs/FEATURES.md)
- CIで型チェック・ビルド・Lint・ユニットテスト・PC/モバイルのブラウザテストを実行します。

Bluesky APIやフィード提供者の仕様・稼働状況により、一部の機能を利用できない場合があります。失敗時はエラーと再試行操作を表示します。ブラウザテストはAPIを模擬し、実アカウントへの投稿やDM送信を行いません。
